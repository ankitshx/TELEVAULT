# TeleCloud — Windows Desktop Platform Specification (Primary Target)

**Platform:** Windows 10 / Windows 11 (x64, ARM64)  
**UI Engine:** Tauri 2 + React + TypeScript + Vanilla CSS  
**Core Runtime:** Rust (`telecloud-core`)  

---

## 1. Overview

Windows Desktop is the **PRIMARY** user interface and experience for TeleCloud. It delivers a fast, native-feeling commercial cloud-drive desktop application.

---

## 2. Windows-Specific Integrations

### 2.1 Credential & Session Security
- Authentication tokens, API keys, and session strings are stored in **Windows Credential Manager** via the Windows Data Protection API (DPAPI) and native Win32 `CredWriteW` / `CredReadW` interfaces (via Rust `wincred` / `keyring` crate).
- Master encryption keys derived via Argon2id are held in memory with guarded memory allocations and wiped on logout using the `zeroize` crate.

### 2.2 Desktop & Shell Integration
- **System Tray:** Background transfer monitoring icon in the Windows taskbar system tray with quick-actions (Pause All, Resume All, Open TeleCloud, Quit).
- **Windows Toast Notifications:** Native notifications via WinRT / `tauri-plugin-notification` for completed transfers, critical errors, and verification results.
- **Drag & Drop:** Full Windows shell drag-and-drop support: dragging files/folders into the TeleCloud window enqueues them into the transfer engine.
- **File Dialogs:** Native Windows Explorer file and directory pickers (`IFileDialog` via Tauri).
- **Startup Option:** Configurable Run-at-Startup entry in the Windows Registry (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

### 2.3 Packaging & Distribution
- **Standalone Installer:** NSIS (`TeleCloud_Setup.exe`) and MSI installer generated by Tauri 2 bundler.
- **Zero Prerequisites:** The final Windows user does not need Python, Node.js, Rust, or any external runtime installed. Everything is bundled into a lean, optimized native binary.

## 3. Desktop Application Architecture

```
+-----------------------------------------------------------+
|                   React + TypeScript UI                   |
|  (Drive View, Breadcrumbs, Transfer Drawer, Settings)      |
+-----------------------------------------------------------+
                            |
                   Tauri 2 IPC Bridge
                            |
+-----------------------------------------------------------+
|                   Tauri 2 Rust Host                       |
|  - Windows Native Shell & Window State                    |
|  - Event Bridge (transfer progress, system tray)          |
+-----------------------------------------------------------+
                            |
+-----------------------------------------------------------+
|                   TeleCloud Rust Core                     |
|  - StorageProvider (Telegram MTProto)                     |
|  - TransferManager (Tokio async worker pool)              |
|  - Chunking & Manifest Engine                             |
|  - SQLite Database (WAL mode, FTS5)                       |
+-----------------------------------------------------------+
```
